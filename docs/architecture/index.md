## In-flight plans

* [github-cli-auth](../features/github-cli-auth/index.md) - in-progress, changes agents.md, providers.md, network.md, workspace-ui.md: Log in to GitHub once through the GitHub CLI in the auth container, then apply that token to every sandbox's gh and git, at create and to existing sandboxes, with a per-sandbox opt-out.
* [host-tool-ssh-access](../features/host-tool-ssh-access/index.md) - in-progress, changes transport.md: Let host SSH clients (e.g. the Claude Code desktop app) attach to a sandbox over the existing exec transport.
* [native-terminal](../features/native-terminal/index.md) - in-progress, changes workspace-ui.md, transport.md: Faster terminal startup: render the sandbox terminal in the main webview over a Rust-owned SSH session that attaches zellij, replacing the zellij web child webview.
* [onboarding-story](../features/onboarding-story/index.md) - in-progress, changes workspace-ui.md: Illustrated onboarding book inside the welcome flow, extensible by chapter, with first-run setup running in the background and reported through the activity center.
* [sandbox-resource-monitor](../features/sandbox-resource-monitor/index.md) - in-progress, changes providers.md, workspace-ui.md: Sample each local sandbox's CPU and memory, show a discrete health indicator with a restart hint, and keep a local usage history that tells the maintainer whether sandboxes need more default memory.
* [paseo-plugins](../features/paseo-plugins/index.md) - planned, changes agents.md: Ship app-owned Paseo plugins in the binary and register them with each sandbox's Paseo daemon at launch, to extend the Agents pane.
* [proxy-toggle-management](../features/proxy-toggle-management/index.md) - planned, changes network.md, providers.md: App-global proxy default and turning the proxy on or off for an existing sandbox by recreating it.
* [tailscale-access](../features/tailscale-access/index.md) - planned, changes remote.md: Join deployed sandboxes to the user's tailnet so their web services are reachable from other devices.
* [chat-mcp-learning](../features/chat-mcp-learning/index.md) - idea, changes agents.md, workspace-ui.md: A built-in offline demo MCP server and MCP visibility in the native chat (server badges on tool calls, a tools popover), so users can learn what an MCP server does with the local model.
* [cloud-sandboxes](../features/cloud-sandboxes/index.md) - idea, changes remote.md: Top-level Cloud Sandboxes nav panel for administering remote Podman hosts, including Oracle Cloud and Google Cloud provisioning.
* [mcp-servers](../features/mcp-servers/index.md) - idea, changes agents.md, network.md, workspace-ui.md: An app-wide library of MCP servers, added by pasting a URL or README snippet and switched on per sandbox, rendered into the native MCP config of Claude Code, OpenCode and pi so Paseo, the terminal and the native chat all use them.
* [proxy-remote-deploy](../features/proxy-remote-deploy/index.md) - idea, changes network.md, remote.md: Let a proxy-enabled sandbox be deployed to a remote host instead of being refused.
